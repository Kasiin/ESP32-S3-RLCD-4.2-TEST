# v0.2.0：实板验证的触摸自检固件

这些分文件与 2026-09-22 已经烧入并完成五点触摸、SD 只读等测试的固件一致。
整合镜像由同一组分文件生成，便于空白板首次烧录；不是另一个功能版本。

| 文件 | 烧录地址 | 用途 |
| --- | --- | --- |
| rlcd-hardware-test-v0.2.0-merged.bin | 0x0 | 整合镜像，适合空白板 |
| bootloader.bin | 0x0 | 分文件启动程序 |
| partition-table.bin | 0x8000 | 分文件分区表 |
| rlcd_hardware_test.bin | 0x10000 | 分文件应用 |
| SHA256SUMS / manifest.json | 不烧录 | 校验值、目标配置、来源与偏移 |

整合镜像与分文件二选一，不要把两种方式的文件重复添加到烧录工具。
整合镜像的填充区会覆盖低地址 NVS/PHY 数据；保留这些数据时使用分文件脚本。

应用大小 327520 字节；SHA256：
`0f8467e6cb20f6865b45e2d2bcf839270629c33d27015e3381f556dbff4b450f`。

详见仓库 [烧录文档](../../docs/FLASHING.md) 和 [实测记录](../../docs/VALIDATION.md)。
