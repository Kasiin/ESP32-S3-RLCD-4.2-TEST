# 测试指南

## 屏幕

BOOT 依次切换状态、全白、全黑、棋盘格、单像素竖条、触摸页。
观察状态页边框是否完整，黑白是否干净，是否缺行、偏移、残影或有坏点。
驱动没有面板读回，串口初始化成功不代表屏幕物理显示成功。

屏幕 SPI 刻意设为 4MHz。原驱动的 `flush slow: 30700 us` 警告属于这个保守速度下的预期：
15KB 全帧传输约 30ms。当前不测试原项目的 60MHz 高速刷新能力。

## 触摸

进入触摸页或发送 `T`。依次点击 1–5 方框，命中后画叉，统计到 `HIT:5/5`。
画横线、竖线、曲线并沿四边滑动，确认坐标与手指一致、没有明显跳点或盲区。
`C` 清除轨迹和命中记录，`T` 返回状态页。KEY 始终保留提示音功能。

RAW 是原始坐标，LCD 是按原项目规则映射的坐标，不自动校准、翻转或旋转。
无意图性的应用手势。画线刷新约 10Hz，不是最高触摸采样率测量。
`H` 打印读取成功/失败、越界、接触次数及目标命中位图；0x1f 表示五点均命中。
五点命中只证明这些位置收到触摸数据，不能证明整片触摸面板无缺陷。

超过 250ms 没有成功读取时，显示 STALE 并中断轨迹；保留上游驱动的恢复机制。
上游还有长时间静止触摸的恢复判定，因此不是无限长按测试程序。
缺少触摸时显示 NOT DETECTED，不影响其余项目。

## 音频与按键

KEY / `A` 输出 880Hz、0.5 秒短音。功放仅在播放时启用，数字音量约 -12dB，采样振幅约满量程 12.5%。
听声音是否清楚、是否明显破音；寄存器读回和 I2S 发送成功不等于扬声器通过。
状态页 B/K/P 是 BOOT/KEY/PWR 的按下次数，串口记录按下与松开。
PWR 不休眠、不关机，以便保持 USB 调试连接。

## 电池、电源与内存

电池读数约每 2 秒刷新一次，`B` 可以主动读取。用万用表对照实际电池电压。
没接电池时 ADC 或充电输出仍可能给出读数，不能据此断言检测到了电池。
软件不检测充电电流、充电终止、保护、纹波或元件温升，不能据此确认电源设计合格。

PSRAM 运行启动检查和 64KB 读写抽测；状态页显示结果。这不是完整内存压力测试。
ALIVE 日志可以观察是否循环重启和明显堆内存下降，但短时间正常不是长期稳定性证明。

## SD 卡

插入已知正常的卡，发送 `S`。成功时输出容量及 `SECTOR READ OK`。
仅初始化卡并读取第一个扇区，**没有挂载、格式化、擦除或写入**。
测试失败可能是无卡、接触、供电、上拉或连线问题，不能仅凭超时认定卡槽坏了。
通过不代表文件系统、写入或高速传输都正常。
