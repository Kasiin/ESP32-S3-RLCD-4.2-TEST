# 实板验证记录

日期：2026-09-22。对象：沿用原板引脚的自制 ESP32-S3 板，16MB Flash / 8MB Octal PSRAM。
不附带设备 MAC、原始 Flash 备份或未整理的串口日志。原始验证 bin 保留编译器的断言字符串，
其中含一个编译时源码目录路径；为保持与实板验证产物逐字节一致，没有修改二进制中的调试字符串。

| 项目 | 已观察结果 |
| --- | --- |
| 刷写 | v2 应用写入并通过哈希校验 |
| 屏幕 | 使用者确认 v1 显示测试正常；v2 沿用原显示驱动和参数 |
| 触摸 | I2C1 0x15，按 CST816 兼容协议读取，400×300；收到 DOWN/MOVE/UP，五点 mask=0x1f |
| 触摸统计 | 一次报告为成功 1074、失败 0、越界 0；五点测试两次均达到 5/5 |
| 音频 | 使用者确认提示音；v2 寄存器读回和音调发送成功 |
| 按键 | 使用者确认既有自检功能正常；串口有 KEY 按下、松开及触发音调记录 |
| 电池 ADC | 约 4.10–4.12V，尚未记录与万用表对照结果 |

| SD | 3840MiB 卡，加入触摸前后首扇区只读测试均通过 |
| 重启 | 测试期间一次计时重置，使用者确认手动复位/重新上电；后续持续输出 ALIVE |
